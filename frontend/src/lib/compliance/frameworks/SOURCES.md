# Framework catalogue sources

Catalogues are generated by `frontend/scripts/extract-oscal-controls.ts` from
public-domain NIST OSCAL content. Regenerate after bumping a pinned source.

## NIST SP 800-53 Rev 5 (Moderate baseline)

- Authority: https://csrc.nist.gov/publications/detail/sp/800-53/rev-5/final
- Source (catalog): https://github.com/usnistgov/oscal-content (nist.gov/SP800-53/rev5/json)
- Source (Moderate baseline profile): https://github.com/usnistgov/oscal-content (nist.gov/SP800-53/rev5/json)

## NIST SP 800-171 Rev 2

- Authority: https://csrc.nist.gov/pubs/sp/800/171/r2/upd1/final (official NIST publication)
- Transcription input: FATHOM5 OSCAL mirror, pinned to commit `66d40d56`
  (https://github.com/FATHOM5/oscal/blob/66d40d56467d0ad2f00692448ac966750bd816fb/content/SP800-171/oscal-content/catalogs/NIST_SP-800-171_rev2_catalog.json)
- The mirror is unofficial. The build-time integrity check in the extraction script verifies
  all 110 controls, 14 families, per-family counts, and title spot-checks against the official
  NIST publication. The script throws if any assertion fails.
- Note: `usnistgov/oscal-content` no longer publishes Rev 2 OSCAL (only Rev 3, 97 controls).
  We target Rev 2 because CMMC Level 2 contracts reference Rev 2.
  Rev 3 (May 2024) exists but is not yet contractually required.

## CMMC Level 2

- Authority: DoD CMMC v2.0 model (https://dodcio.defense.gov/CMMC/Model/)
- CMMC Level 2 practices are derived 1:1 from NIST SP 800-171 Rev 2 (same 110 requirements).
  Control IDs are prefixed with the domain abbreviation: e.g., `AC.L2-3.1.1`.
- Provenance: same FATHOM5 OSCAL mirror as 800-171 Rev 2 above (same integrity check applies).
